NEON DODGE — my AI agent built a game from one prompt. One prompt in, a playable neon dodge game out: a 38-second video shows the prompt, the agent writing the code, the game actually playing (autopilot ship dodging blocks, grabbing stars, score climbing), and ends on make.fun's referral card. A resubmit of the post-x entry with a longer cut — the first post stalled at 2 views.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` from this repository to `/output/POST.json`, byte for byte. `POST.json` holds the address of the X post carrying the video (placeholder until the video is posted).
